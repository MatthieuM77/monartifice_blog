# Photos produit

**Nommez chaque fichier par la référence du produit**, rien d'autre : `sc22384.jpg`.
Le générateur reconnaît la référence et remplit la slide tout seul — comme il le fait déjà
pour les codes de plan des photos de chantier.

Plusieurs vues pour une même référence : ajoutez un suffixe.

```
sc22384.jpg          ← la vue principale, de face
sc22384-troisquarts.jpg
sc22384-echelle.jpg  ← tenue à bout de bras
```

La vue de face est celle qui sert par défaut. Fond neutre de préférence : elle se détoure
pour se poser sur les fonds nuit de la marque.
